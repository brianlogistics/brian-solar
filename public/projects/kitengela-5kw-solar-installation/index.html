Solar Project — Kitengela, Kajiado County

5kW Off-Grid Solar Installation in Kitengela

Complete Residential Solar Installation

Location: Kitengela, Kajiado County

Total Investment: KSh 345,000

Our client wanted to reduce high electricity costs and improve power reliability. We designed and installed a complete 5kW solar system using SRNE lithium battery storage and a hybrid inverter.

System Highlights

  • 5kW SRNE Hybrid Inverter
  • SRNE Lithium Battery Storage
  • 6 × 615W Solar Panels
  • Electrical protection
  • Complete residential system installation

Project Summary

The completed installation combines rooftop solar generation, hybrid inverter technology, lithium battery storage and electrical protection into a residential solar power system.
