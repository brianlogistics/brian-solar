Solar Project — Kitengela, Kajiado County

5kW Off-Grid Solar Installation in Kitengela

Project Overview

Location: Kitengela, Kajiado County

Total Investment: KSh 345,000

Our client wanted to reduce high electricity costs and improve power reliability. We designed and installed a complete 5kW solar system using an SRNE hybrid inverter and SRNE lithium battery storage.

System Highlights

  • 5kW SRNE Hybrid Inverter
  • SRNE Lithium Battery Storage
  • 6 × 615W Solar Panels
  • Electrical protection
  • Complete residential system installation
